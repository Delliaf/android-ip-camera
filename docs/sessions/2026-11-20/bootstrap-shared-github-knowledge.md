# Создание единой памяти для нескольких независимых чатов

- **Статус:** implemented (documentation / process only; no LG APK built)
- **Дата:** 2026-11-20
- **Запрос пользователя:** универсальный промпт, с которого любой новый чат сможет работать с форком GitHub без восстановления истории; параллельные чаты должны независимо делать свои функции, передавать всю историю/технические детали через множество файлов GitHub.
- **Репозиторий:** https://github.com/Delliaf/android-ip-camera
- **Изменяемая ветка:** `main` — **только документация и правило docs-only CI**, экспериментальный код LG-H872 не модифицировался.
- **Живой статус до изменений:** 5 открытых draft PR; актуальный наиболее полный экспериментальный stack заканчивается `fix/lg-g6-metrics-visible` / PR #5. Тестовый APK `0.18.0-delliaf.8` собран на функциональном SHA `5853755367ae8dc99c338851b2de22214ec8b07a`, [Actions #44591663439](https://github.com/Delliaf/android-ip-camera/actions/runs/44591663439). Не является реальным аппаратным тестом.

## Реализованная структура (в main)

- `AGENTS.md` — старт и правила агента.
- `docs/coordination/START_HERE.md`, `BRANCHES_AND_PRS.md`, `PROJECT_ARCHITECTURE.md`, `RELEASE_AND_TEST_POLICY.md` — общий контекст.
- `docs/coordination/PARALLEL_WORKFLOW.md`, `INTEGRATION_PLAYBOOK.md` — безопасное независимое выполнение и сборка PR.
- `docs/coordination/UNIVERSAL_PROMPT.md` — один промпт для любых новых чатов.
- `docs/workstreams/*` — доменные технические заметки о Camera0, ONVIF, benchmark 4,5×, CPU/температуре, ABI/CI.
- `docs/sessions/README.md`, `docs/templates/SESSION_TEMPLATE.md` — индивидуальная хронология каждой задачи.
- `docs/decisions/ADR-0001*`, `ADR-0002*` — мотивация процесса и инженерных ограничений.
- `docs/history/DEVELOPMENT_HISTORY_2026-11-19.txt` — **полная неизменяемая копия** старого журнала с экспериментальной ветки.
- `.github/pull_request_template.md` — шаблон PR со ссылкой на shared session и SHA.
- `.github/workflows/reproducible-build.yml` в `main`: `paths-ignore` для `docs/**`, `AGENTS.md`, `README.md`, чтобы история, которую параллельно обновляют чаты, не вызывала сборку APK каждый раз.

## Принятое решение

**Не поддерживать одну общую изменяемую летопись**. Каждый чат пишет собственный файл `main/docs/sessions/YYYY-MM-DD/<unique-task>.md`, и для сложной темы подробный `main/docs/workstreams/<domain>/<unique-task>.md`, без правок чужих файлов. Код — своя branch, draft PR на правильную base. Общие индексы и release-сведения интегрирует отдельный исполнитель.

## Ограничения / что ещё проверить

- Это изменение правил взаимодействия с GitHub, а **не изменение исходников камеры**; APK для него не требуется и не заявлен.
- GitHub write-доступ должен быть подключён и у каждого нового чата. Если его нет, общий механизм записи не работает — нельзя имитировать сохранение.
- Текстовые справочники снимка могут устаревать; каждый новый чат должен прочитать живые ветки/PR и новые session файлы.
- При параллельном создании уникальных файлов в main несколько чатов не перезапишут одну и ту же историю. Редактирование централизованных индексов остаётся ролью интегратора.
- Копию архива не редактировать; новые эксперименты добавлять отдельными файлами.

## Продолжение

Следующий чат получает только `https://github.com/Delliaf/android-ip-camera` и универсальный промпт, читает `main/AGENTS.md`, проверяет актуальные refs/PR и начинает пользовательскую задачу с отдельной сессией. Для крупной новой функции создать отдельный workstream файл. После CI записать точный SHA, run, Artifact и **отдельно** результат на LG-H872.
