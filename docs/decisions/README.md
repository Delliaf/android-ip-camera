# Архитектурные решения (ADR)

ADR фиксирует не просто «что написали», но **почему выбрали именно такой путь**, какие альтернативы отвергли, как проверить ограничения и что потребует миграции.

- [ADR-0001: независимые чаты + GitHub как единая память](ADR-0001-parallel-chats.md)
- [ADR-0002: изолированные ветки и проверяемый статус сборки](ADR-0002-integration-and-verification.md)

Новые независимые решения оформляй как **новые файлы** `ADR-NNNN-<slug>.md` в `main/docs/decisions` (проверив существующие номера через GitHub). Не редактируй чужие ADR без согласования/ссылки на superseding ADR, чтобы несколько чатов не теряли мотивы друг друга. Новые гипотезы без реальных данных помечай `proposed`, а не `accepted`.
