# Направления разработки (доменный контекст)

Здесь хранится **предметная** документация, которую новый чат читает **только для нужной задачи**, после общего [START_HERE](../coordination/START_HERE.md). Каждая запись домена — технический конспект с файлами кода, состоянием, тестами и нюансами.

Общие опорные документы:
- [Камера LG G6 Camera0: ISO, ZSL, GPU ROI, фокус](camera-lg-g6.md)
- [ONVIF / RTSP / go2rtc](onvif-network.md)
- [Автобенчмарк изображений 4,5×](benchmark-4p5x.md)
- [CPU / температура / веб-интерфейс](telemetry-and-web.md)
- [Сборки / GitHub CI / APK](build-ci.md)

**Новые задачи:** не вставляй весь текст в этот индекс и не переписывай файл коллег. Создай отдельный уникальный файл `docs/workstreams/<domain>/<task-id>.md` и свой `docs/sessions/YYYY-MM-DD/<task-id>.md` в main. Ссылайся на него из своего PR. Общие индексы интегратор обновит позднее, чтобы параллельные чаты не конфликтовали.

Статус и факты в документах — срез на 2026-11-20. Последние исходники и CI GitHub имеют приоритет, а `main` не содержит все экспериментальные функции. Всегда уточняй, на какой ветке находится класс и тест.
