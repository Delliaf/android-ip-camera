IMPORTANT FOLLOW-UP — 2026-11-19, ROOT CAUSE: DIRECT AE FPS RANGE
---------------------------------------------------------------------------
Inspected the LG-H872 Camera0 metadata in the uploaded ZIP and compared our
code paths. The actual Camera2 CONTROL_AE_AVAILABLE_TARGET_FPS_RANGES list
includes [15,15], [20,20], [2,24], [24,24], [2,30], [30,30].
LG Direct Camera2 originally used:
    ranges?.firstOrNull { it.lower <= fps && it.upper >= fps }
At 15 fps this picks [15,15] and restricts AUTO exposure to ~66.7ms.
CameraX instead uses:
    ranges?.maxWithOrNull(compareBy({ it.upper - it.lower }, { it.upper }))
which picks the much wider [2,30], permitting longer night exposures.
THIS IS A MAJOR LIKELY CAUSE of the user's very dark Direct picture, and
is more concrete than assuming that a manual ISO 800 ceiling is the cause.
No claim that it is the only cause; OEM ISP tone processing still differs.
The test archive shows actual AUTO ISO2728 @ 66.667ms while direct fixed
range; the wide-range fix must be tested physically and FPS tradeoff noted.
